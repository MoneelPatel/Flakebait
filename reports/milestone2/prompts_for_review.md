## Public fields become unreadable when a setter exists

When a class has a public field and a setter for the same property, `Reflector` does not expose the field as readable if the class has no getter. For example:

```java
class Example {
  public String name;
  public void setName(String name) { this.name = name; }
}

Reflector reflector = new Reflector(Example.class);
```

I expect `reflector.hasGetter("name")` to be `true`, since the public field can be read. Instead it is `false`, and `name` is missing from the readable property names. As a result, code that reads the property through MyBatis reflection fails with a “no getter” error. This also affects classes with other properties: their readable property list can omit the field-backed property.

The test `shouldResolveGetterTypeFromPublicField` in `org.apache.ibatis.reflection.ReflectorTest` fails because of this bug. You can run it with:

```
mvn test -Dtest=ReflectorTest
```

Please fix the bug.
